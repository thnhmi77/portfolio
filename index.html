Projects

SeatSaver

SeatSaver is an application intended for University of Pittsburgh students to both locate and reserve vacant study spots on campus. It's implemented using React and Node.js to provide an accessible, user-friendly UI design that enables users to view academic buildings, the study spaces and rooms available within them, and reserve specific rooms for the future. Through this project, not only did I learn more about React and MongoDB, our choice of database, but I also familiarized myself with the Scrum process. Through this framework, I was taught the importance of communication and adaptation. The development of SeatSaver relied extremely heavily on ensuring a tight understanding of our intended architectures, features, and components, and also on the ability to work off of someone else's code that is not your own. This project really put into perspective the depth of software engineering and its multitude of steps that are as integral to the process of development as writing the code itself.

Intrusion Chain Finder

This project identifies valid paths between network systems by using a recursive backtracking system with system access constraint checking within a hop limit. It's made in Java! The project helped me grow more confident in implementing backtracking algorithms while acting as a brief introduction to network systems.
